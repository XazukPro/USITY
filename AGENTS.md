# Правила разработки USITY

- Перед изменением поведения сверяйся с `docs/product/mvp.md`. AI-часть дополнительно сверяй с `docs/research/ai-course-notes-ru.md`.
- MVP к 15 декабря 2026: Telegram, ручное расписание, проверка AI-черновиков админом, ДЗ внутри карточки пары, материалы, личные задачи и базовый offline-режим. Расширения после MVP не добавляй без отдельной задачи.
- Предпочитаемый стек: Flutter/Dart (iOS и Android), Python/FastAPI (API), aiogram (бот), PostgreSQL (данные), S3-совместимое хранилище (файлы), Redis с очередью фоновых задач (OCR/LLM), SQLite на устройстве (offline). Конкретные библиотеки закрепляй при реализации соответствующего модуля.
- Модель только предлагает черновик. Публикация, изменение или удаление группового ДЗ требует действия админа. Сохраняй исходный контекст, версию промпта/модели и решение человека для оценки качества.
- Не передавай в AI постороннюю переписку. Обрабатывай только подключенную Telegram-тему. Не сохраняй секреты, реальные чаты или личные данные в Git.
- Сохраняй существующие изменения других участников. Работай в отдельной ветке для каждой задачи; перед объединением запускай относящиеся к изменению проверки. Не коммить сгенерированные сборки, локальные базы, ключи и временные файлы.
- Готовые изменения коммить и отправляй в `XazukPro/USITY`. В описании PR указывай, что изменено, как проверено и какие ограничения остались. Не утверждай, что тесты прошли, без их запуска.
- Новые договоренности по продукту вноси в спецификацию; технические решения и команды запуска держи рядом с соответствующим модулем.
