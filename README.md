# USITY

Мобильное приложение для студентов: расписание, домашние задания и учебные материалы группы. Telegram-бот получает сообщения из выбранной темы, AI предлагает черновики, администратор проверяет их перед публикацией.

Реализован первый связанный учебный прототип: агентский черновик → API проверки → публикация через Flutter Android → ДЗ внутри пары и личное выполнение. Используются синтетические сообщения и фиксированный ответ модели; живая Telegram-интеграция и остальные части MVP ещё в разработке.
