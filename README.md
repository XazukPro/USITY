# USITY

Мобильное приложение для студентов: расписание, домашние задания и учебные материалы группы. Telegram-бот получает сообщения из выбранной темы, AI предлагает черновики, администратор проверяет их перед публикацией.

Проект находится на этапе подготовки. Код приложения, сервера и бота пока не добавлен.
