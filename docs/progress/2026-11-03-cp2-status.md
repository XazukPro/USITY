## Проверки и честные ограничения метрик

- Backend: 32 теста прошли на SQLite и PostgreSQL 17. Проверены чужая группа,
  роли, просроченная сессия, будущая пара, атомарный откат, одновременные решения,
  повтор события и конфликт версий выполнения. Это результаты тестового набора,
  а не оценка надежности на реальных пользователях.
- Flutter: 9 unit/widget-тестов; анализатор без замечаний. Android API36 debug
  собран и запущен; публикация через UI проверена на локальном сервере.
- Демонстрация API: до проверки 0 ДЗ, после 1; после выполнения у одного
  пользователя 0, у второго 1. Состояние хранится в БД.
- Precision/recall LLM, задержка Telegram→черновик и стоимость обработки пока
  **не измерены**. Фиксированный ответ модели нельзя использовать как AI-метрику.
- В backend-тестах есть deprecation warning Starlette/httpx, проверки проходят.

## Изменение плана и риски

Разработка идет по связанным вертикальным сценариям, чтобы на КП2 показать
реальные компоненты. Провайдер не выбран, поэтому интерфейс и хранение работают
с синтетическим ответом. Email OTP временно заменен только на локальном стенде
случайными сессиями с ограниченным сроком. Общее приложение и backend ведет
Антон с помощью Codex; остальные участники реализуют своих агентов. Финальный
MVP к 15 декабря остается целью, текущий стенд ему еще не соответствует.
