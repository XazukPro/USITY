# Стек технологий

Состояние на 9 ноября 2026 года. Версии зависимостей приведены в [mobile/pubspec.lock](../../mobile/pubspec.lock), [backend/requirements.lock](../../backend/requirements.lock) и дополнительных файлах зависимостей. Сервисы, отмеченные как планируемые, требуют подключения и проверки на постоянном стенде.

| Область | Технологии и назначение | Состояние |
| --- | --- | --- |
| iOS и Android | Flutter и Dart, общая кодовая база | Прототип собирается для обеих платформ |
| Дизайн | Flutter Material, собственные компоненты и токены, шрифты Onest и JetBrains Mono | Токены и компоненты в проекте |
| Мобильная сеть | http, HTTPS API; app_links для ссылок | В клиенте |
| Локальные данные | SQLite через sqflite; sqflite_common_ffi для тестов; shared_preferences для настроек | Базовый offline и синхронизация личных задач и отметок ДЗ |
| Сессии | flutter_secure_storage, iOS Keychain и Android-хранилище | Реализовано в клиенте |
| Файлы на устройстве | file_picker, path_provider, open_filex, url_launcher, share_plus | Выбор, кеширование и открытие средствами устройства |
| Backend | Python 3.14, FastAPI, Pydantic, Uvicorn, SQLAlchemy | API и локальный стенд |
| База | PostgreSQL, psycopg; SQLite для локальной разработки | Миграции SQL 001–005, тесты на SQLite и PostgreSQL |
| Объектное хранилище | S3-совместимый API, boto3; приватный локальный каталог | Локальный сценарий реализован, постоянное S3 нужно проверить |
| Telegram | Telegram Bot API, aiogram | Текстовый приём темы в отдельном серверном контуре |
| AI | Python, пять агентов, единый EventBundle, заменяемый интерфейс провайдера, HTTPX, адаптер GigaChat/Chat Completions | Реализации есть в ветке агентов, интеграция с мобильной веткой впереди |
| OCR | Заменяемый адаптер распознавания фото | Планируется, провайдер не закреплён |
| Фоновые задания | Отдельный обработчик, PostgreSQL; Redis и очередь при необходимости | Постоянный worker и инфраструктура требуют интеграции |
| Почта | SMTP с TLS и одноразовыми кодами | Код входа реализован, поставщик для реального стенда не выбран |
| Push | APNs для iOS; канал Android зависит от выбранных сервисов и дистрибуции | Реализация и проверка на устройствах впереди |
| Тестирование | pytest, FastAPI TestClient, Flutter test, Ruff, flutter analyze, Android Emulator, iOS Simulator | Используются; финальная проверка на физических устройствах впереди |
| Разработка | Git, GitHub, pull request, Xcode, Android SDK/Studio | Используются |

Итоговый выбор облака, хостинга, OCR, почты, LLM-провайдера и Android push требует отдельной проверки доступности, стоимости и условий обработки данных в России. Не хранить ключи, реальные чаты и персональные данные в Git.
