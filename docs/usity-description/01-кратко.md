# Краткое описание USITY

USITY — бесплатное приложение для iOS и Android, которое помогает студентам ориентироваться в расписании, домашних заданиях и учебных материалах своей группы.

Telegram-бот получает сообщения из выбранной учебной темы, пять специализированных AI-агентов находят возможные задания и материалы, а староста или администратор проверяет предложения. Подтверждённое ДЗ появляется у конкретной пары с учётом подгруппы. Студент также планирует личные дела и отмечает выполнение для себя.
