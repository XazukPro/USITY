Базовое описание подготовлено 9 ноября 2026 года. Текст описывает как целевой MVP, так и уже созданные компоненты. Состояние объединения веток и признаки готовности приведены в файле о статусе. Проверка сквозного подключения агентов к Telegram остаётся отдельной задачей.

Для разрешения расхождений использовать более поздние согласованные решения и [продуктовую спецификацию дизайн-передачи](https://github.com/XazukPro/USITY/blob/codex/design-handoff/docs/product/mvp.md). Исходная [спецификация MVP](../product/mvp.md) и [план интеграции](../development/ai-pilot-release.md) содержат дополнительный контекст.

## Как обновлять описание

Изменяя функциональность, дизайн, архитектуру, зависимости или график, обновляйте связанные документы в том же pull request. В документе о статусе указывайте дату, ветку или PR, выполненную проверку и её результат. Запланированные возможности обозначайте как планы до их реализации и проверки. При новом продуктовом решении обновляйте также действующую спецификацию, а при изменении команд запуска — README соответствующего модуля. Правило закреплено в [AGENTS.md](../../AGENTS.md).
