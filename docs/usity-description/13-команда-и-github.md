По требованию проекта команда готовит минимум пять независимых специализированных AI-агентов. Итоговое закрепление авторства каждого агента и фактический вклад участников следует сверять по коду, задачам и принятым pull request. Пять ролей и их интеграция описаны в [AI и Telegram](07-ai-и-telegram.md).

## Организация кода

Репозиторий — [XazukPro/USITY](https://github.com/XazukPro/USITY). Работа ведётся в отдельных ветках. Изменения отправляются через pull request с описанием результата, проверок и оставшихся ограничений. Перед объединением проверяются конфликты, тесты затронутой области и актуальность описаний.

Ветки приложения и пяти агентов на момент подготовки этого документа требуют объединения. До интеграции нельзя считать общий поток Telegram → пять агентов → приложение проверенным только по тестам отдельных веток.

## Что фиксировать по каждой задаче

- Ответственного, границы задачи и критерий готовности.
- Ссылку на ветку, задачу или pull request.
- Проверенные сценарии, команды и результаты.
- Фактические изменения, оставшиеся ограничения и влияние на другие компоненты.
- Обновления соответствующих файлов в этой папке и основной спецификации.

Не хранить в Git ключи, токены, реальные чаты, локальные базы, скачанные файлы пользователей и результаты сборки.
