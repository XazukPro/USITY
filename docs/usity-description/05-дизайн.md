# Дизайн USITY

## Принципы

Интерфейс спокойный и минималистичный, с очевидной иерархией времени, названия занятия и действия. Главный экран — расписание. Дизайн передан как набор экранов, прототипов и токенов, включая светлую и тёмную темы. По умолчанию используется тема устройства, пользователь может выбрать тему в настройках.

## Навигация и экраны

Четыре основные вкладки — «Расписание», «Задачи», «Материалы» и «Настройки». Административные функции доступны из соответствующих разделов. В задачах групповые ДЗ и личные дела сортируются по датам с переключением фильтров.

На расписании сверху располагаются месяц, недельная строка и компактные элементы управления. Дата выбранного дня и учебная неделя отделяют навигацию от содержимого. Слева от событий расположена вертикальная временная линия, объединяющая пары и личные задачи. Счётчик невыполненных ДЗ находится у соответствующей пары, подробный текст открывается в карточке пары.

Поддерживаются просмотр дня и недели, выбор даты, добавление задачи, выбор времени и длительности, перенос задачи удержанием, отметка выполнения, материалы и настройки. Редактор старосты проводит через создание группы и расписания. Очередь проверки показывает исходный контекст и предложенные правки.

## Визуальная система

- Базовая типографика — Onest, для технических значений предусмотрен JetBrains Mono.
- Светлый фон `#f8f7fc`, поверхность `#ffffff`. Тёмный фон `#15141d`, поверхность `#1e1d2a`.
- Акцентные цвета, виды занятий, отступы, радиусы и состояния задаются через токены, а не отдельными произвольными значениями.
- Цвет предмета задаёт администратор из ограниченной палитры. Элементы управления и статусы должны оставаться различимыми в обеих темах и при увеличенном тексте.

Точные цвета и значения находятся в [tokens.json](../design/tokens.json). Полный переданный дизайн-проект с описанием экранов, светлыми и тёмными PNG и HTML-прототипами находится в [ветке дизайн-передачи](https://github.com/XazukPro/USITY/tree/codex/design-handoff/docs/design). Реализацию экранов сверяют с этими эталонами и утверждёнными продуктовыми правилами.

## Состав экранов

| Экран | Содержимое и действия |
| --- | --- |
| День | Выбор даты, ось времени, пары и личные задачи, создание и перенос задачи |
| Неделя | Семь дней, занятия и задачи, переход к выбранному дню |
| Пара | Тип, время, преподаватель, аудитория или ссылка, подгруппа, пункты ДЗ и материалы |
| Редактор задачи | Текст, дата, необязательное время, длительность и сохранение |
| Задачи | Групповые ДЗ и личные задачи, фильтры, сортировка по срокам, отметка и восстановление |
| Материалы | Поиск и фильтр по предметам, структурированный каталог, открытие файла или ссылки |
| Настройки | Профиль, подгруппы, тема, уведомления и действия с аккаунтом |
| Проверка | Исходные сообщения, предложения агентов, поля для исправления и действия админа |
| Настройка группы | Создание группы, предметов, подгрупп, расписания, подключение темы и приглашение |

Для приёмки сравниваются обе темы, небольшая ширина экрана, увеличенный шрифт, пустые состояния, ошибки и доступность основных действий. Индикаторы демоданных и ошибок должны быть понятны пользователю.
