# Проверка черновика учебного материала

Этот модуль — отдельный вклад Алексея в агент материалов Ивана. Он не вызывает
OCR или GigaChat, не классифицирует материал и не публикует его. Иван может
вызвать `validate_material_proposal(bundle, proposal)` после получения ответа
модели и до добавления карточки в очередь администратора.

## Контракт

`bundle` содержит `group_id`, `chat_id`, `connected_chat_id`, `topic_id`,
`connected_topic_id`, `messages`, `subjects`, `assignments` и `categories`.
Каждое сообщение содержит `id`, `chat_id`, `topic_id`, текст и список
`attachments`. Для файла или фото вложение содержит `id`, `kind`, `size_bytes`,
`mime_type` и необязательное `file_name`; для ссылки — `id`, `kind=link`, `url`.
Каталоги предметов и категорий — списки объектов с `id`; ДЗ дополнительно
содержит `subject_id`. Категории передаются из группы, поэтому новые категории
администратора работают без изменения кода.

`proposal` — объект с обязательными полями `kind=material`,
`source_message_ids`, `material_type=file|link`, `attachment_id` или `link_url`,
`category_id`, `subject_ids`, `assignment_ids`, `uncertain`, `reason`.
Предложение относится к одному файлу или одной ссылке. Для неизвестных
категории, предметов и связи с ДЗ используется `null` и `uncertain=true`.
Пустой список `assignment_ids` означает, что связи с ДЗ нет.

Функция возвращает проверенную копию предложения либо вызывает
`MaterialValidationError`. Она проверяет принадлежность исходной теме,
существование ID и связи ДЗ с выбранным предметом, наличие файла или ссылки
в указанных сообщениях, формат и размер файла. Предел — 100 000 000 байт.
Проверка расширения и MIME основана только на метаданных; анализ содержимого
файла выполняется при загрузке в общем backend. Администратор всё равно
принимает решение о публикации.

## Проверка

```bash
python3 -m unittest discover -s backend/agents/materials/tests -v
```

Формат общего `EventBundle` пяти агентов ещё согласовывается. При интеграции
Иван и команда могут адаптировать имена полей, сохранив проверки и тестовые
сценарии этого модуля.
